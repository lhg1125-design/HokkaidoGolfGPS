# 야디지 좌표 기준서

## YARDAGE_IMAGE PASS 좌표

기준 이미지: asset_bg_yardage_fix_preview.png
해상도: 941 x 1672 px

```yaml
yardage:
  x: 378
  y: 361
  width: 254
  height: 998
  scale: 1.0
  crop: false
  stretch: false
  align:
    tee_box_0m: bottom
```

## 핵심 ALIGN 규칙 (중요)

- 야디지 이미지별 W/H 사이즈는 홀별로 다를 수 있음
- 고정 기준은 이미지 크기가 아니라 **TEE BOX 0m 위치**임
- 모든 야디지는 아래 기준으로 Overlay 정렬

```yaml
anchor:
  type: tee_box_0m
  position: bottom
  rule: tee_box_0m_line_align
```

즉, 야디지 이미지 크기/비율이 변경되어도
`TEE BOX 0m ALIGN LINE = bottom anchor` 기준으로 배치한다.
