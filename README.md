# 北海道ゴルフ GPSキャディ

Hokkaido golf trip GPS caddie prototype for 2026-08-24~26.

- Distance unit: **m**
- Android Studio not required
- APK is built with GitHub Actions
- Target courses: 上士幌ゴルフ場 / 富良野ゴルフコース / サホロカントリークラブ

> Current course coordinates are prototype/demo data. Field-ready coordinates will be added in the next sprint.
